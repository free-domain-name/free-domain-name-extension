Free Domain Name

Settings

The extension reads a public JSON registry over HTTPS. Changes are only applied after the payload passes validation, including a check that no managed TLD is delegated in the real IANA root zone.

Registry

Use the organization repository once it is public, or a raw endpoint you control.

HTTPS only. The response is capped at 5 MB and must validate against client schema version 2.

Cloudflare (https://cloudflare-dns.com/dns-query) and Google (https://dns.google/resolve) work. Loopback HTTP is accepted for local testing only.

Resolver proxy

DNS-like mode keeps the requested name in the address bar and connects to the record target. It requires the small local proxy; without it the extension falls back to redirects.

Start it with npm run resolver. The proxy only listens on 127.0.0.1. HTTPS is not handled by this mode.

Status

A failed refresh keeps the last valid registry instead of dropping all rules.

Permissions: declarativeNetRequest (redirect fallback), proxy (route only registry-managed HTTP names to the loopback resolver), storage, alarms, and host access for all sites. Host access is required by Chrome to intercept an arbitrary community TLD; no page content is read or modified. The resolver proxy is an optional local companion and never runs in the cloud.
